Água em Dia 💧

Plataforma para registro, monitoramento e priorização de ocorrências de vazamentos de água.

Sobre

O Água em Dia busca otimizar a identificação e o acompanhamento de vazamentos, utilizando informações das ocorrências para apoiar a priorização dos atendimentos e reduzir o desperdício de água.

Tecnologias

* Backend: Java 21 e Spring Boot
* Frontend: HTML, CSS e JavaScript
* Banco de dados: Microsoft SQL Server
* Migrações: Flyway
* Autenticação: Spring Security e JWT

Estrutura

* backend/ — API e regras de negócio.
* frontend/ — interface da aplicação.
* docs/ — documentação técnica.
